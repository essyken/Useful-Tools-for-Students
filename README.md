## Introduction

This guide covers useful tools that student should know about.
In today’s digital learning environment, students have access to a wide range of tools designed to improve productivity, organization, 
research, collaboration, and academic performance. These tools support different aspects of student life, from taking structured notes 
and managing assignments to conducting research and creating presentations. By leveraging technology effectively, students can streamline 
their workflows, reduce stress, and focus more on understanding concepts rather than managing tasks manually.

Useful student tools generally fall into key categories such as note-taking applications, task managers, cloud storage platforms, 
research databases, writing assistants, and collaboration software. Each category serves a specific academic purpose, and when used 
together, they create an efficient study system that enhances time management, information retention, and project coordination. 
Learning how to select and use the right tools is therefore an essential skill for modern students, as it promotes independence, organization, and academic success.

# NOTION
**Notion** is an all-in-one digital workspace that:
- combines notes
-  task management
-  databases
-  calendars
-  collaboration tools in a single platform.
-  _Instead of juggling multiple apps, you can organize your academic life in one system._

## 🎯 Use Notion

- **Lecture Notes** — structured pages with headings, code blocks, tables, and images.
- **Assignment Tracker** — deadlines, priorities, progress status
- **Study Planner** — weekly schedules + exam countdowns
- **Research Hub** — collect sources, citations, and summaries
- **Group Projectss** - hared pages with teammates
  
## ⚙️Key Features

- **Block system** → every element (text, list, table) is movable and customizable
- **Database**s → tables, boards, calendars, lists all from same data
- **Templates** → ready-made study planners, note systems, habit trackers
- **Cloud sync** → works on phone, laptop, or browser
- **Collaboration** → real-time editing with classmates

  ## 👍 Advantages

- Highly customizable
- Replaces multiple apps
- Clean interface
- Great for organization lovers

## 👎 Limitations

- Takes time to learn
- Requires internet for full functionality
- Can become messy if poorly structured
